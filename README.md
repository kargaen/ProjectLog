# ProjectLog

ProjectLog is a fast, private, local-first desktop app for tracking work as it happens.

## Mission

> *ProjectLog exists to make daily work tracking effortless: helping people capture what they work on, when they worked on it, how many hours they spend on projects each day, and the context behind that work through a fast, private, local-first desktop app that turns lightweight activity logging into reliable timesheet-ready insight.*

## What ProjectLog is for

ProjectLog is built for people who need a lightweight way to:

- track which project they are actively working on
- capture short comments or context as work changes
- build a trustworthy daily record of time spent
- prepare timesheet-ready summaries from real activity

It is intentionally focused. It is not meant to be a full project-management system. Its purpose is to reduce friction around daily hour logging.

## Core Principles

- **Fast to use** — logging work should take seconds
- **Local-first** — your project data and work history stay on your machine
- **Low friction** — the app should help you log work, not interrupt it
- **Timesheet-oriented** — the recorded activity should support reliable daily hour reporting
- **Focused scope** — simple project logging over heavyweight workflow management

## For users

ProjectLog helps you keep a running record of:

- what you worked on
- when you worked on it
- how your day was split across projects
- any short notes needed to remember context later
